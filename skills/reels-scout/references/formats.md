# Viral Reel format vocabulary

Use these names in the report so formats can be compared across sessions. Add new ones when you see a repeatable skeleton that doesn't fit.

| Format | Skeleton | Typical hook |
|---|---|---|
| Reaction / "watch their face" | Setup → person tries/receives product → face changes → payoff | "Watch her face when…" |
| Store shock → home | Shock in store aisle → shelf → unboxing → product in use montage | "Babe, the dog doesn't need that" / "Me: 😍" |
| POV | First-person moment the viewer recognises | "POV: you finally…" |
| Before / after | Problem state → transformation | "Day 1 vs day 30", "Without vs with" |
| Split screen | Two versions side by side at once | "Same morning, one of us made a mistake" |
| "Things my X does" | Relatable list of quirks, quick cuts → product payoff | "Things my always-cold wife does" |
| Skit / prank | Short scripted scene with a twist | "My husband secretly…" |
| ASMR / satisfying close-up | Macro of a mechanism, click, pour, fit | "The most satisfying sound…" |
| Unboxing | Box → reveal → first use | "Finally came…" |
| Kindness / wholesome | Giving something to someone deserving | "We left this for our mail carrier…" |
| Challenge / test | Endurance, durability or comparison test | "Last one to go inside wins" |
| Montage of many | Same product on many people/pets/places | "Every dog mom NEEDS this" |
| Problem callout | Talks to a pain directly | "If your hands are always cold, watch this" |
| Tutorial / how it works | 3 steps | "How it works 👇" |
| Green screen / reply to comment | Answers a comment or question | "Replying to: do they actually work?" |

## Hook mechanics to name
Question · POV · reaction face · unexpected object behaviour · relatable complaint · "don't show this to…" · shocking number · comment reply · pattern interrupt (sudden cut, odd framing) · cute/animal in frame 1.

## Signals worth noting
- Views vs follower count (a 5K-follower account with 2M views = the *format* did it, not the audience).
- Shares and saves > likes = strongly transferable.
- Comments asking "where/link/price" = buying intent for that product.
- A sound with 1K–50K uses that is climbing = early; 1M+ = late.
