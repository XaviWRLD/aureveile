# Product verdict: Winning Products Framework (organic)

Score each product you spot. Organic sales live on the product being scroll-stopping by itself, so Wow Factor counts double.

| Factor | Question | Strong / Mixed / Weak |
|---|---|---|
| Wow Factor (×2) | Would it stop a scroll in 1 second, with no explanation? | |
| Utility | Does it solve a real problem or deliver a clear feeling? | |
| Use Case | Will people use it more than once, in a moment they can picture? | |
| Mass appeal | Can a big, obvious group buy it (pet owners, parents, gift buyers, everyone who's cold)? | |
| Organic proof | How many Reels/accounts are winning with it *right now*? Buying-intent comments? | |
| Timing | Rising, peaking or already burnt out? Seasonal window left? | |
| Price / margin feel | Impulse price ($20–60)? Looks like it costs $3–15 to source? | |
| Fit with the user | Same audience or season as their stores (winter, gifting, pets, Germany)? | |

## Verdict rules
- **🚨 RUN IT**: Wow Factor strong, organic proof from **2+ accounts or 3+ Reels** in the last ~30 days, timing not peaked, and an impulse price. Tell the user directly: "Hey, run this." Give 3 hooks and the checks before ordering (sample, supplier cost, shipping time to their markets, season length).
- **👀 WATCH**: one viral Reel only, or timing/price unclear. State the one thing that would upgrade it.
- **❌ PASS**: weak wow, saturated (everyone is running it with the same video), already past its peak, or a fragile/complex product that will cause returns.

Bias: be decisive in both directions. Say RUN IT with conviction when the evidence is there, and PASS without guilt when it isn't. Never upgrade a product just to have something to report.

## What to check before ordering (put this under every RUN IT)
1. Supplier listing and landed cost (AliExpress / CJ / Zendrop as a floor).
2. Shipping time to the target market (US/UK/CA or Germany).
3. Whether the Facebook Ads Library already shows lots of long-running ads (fine, it means demand; too many identical videos means saturated).
4. Season: how many selling weeks are left.
