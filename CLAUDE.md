# myHeatedGloves – working preferences

## Image / video generation (user feedback, Nov 2026)
- AI-looking, unrealistic images are NOT acceptable. Realism is the top priority.
- Preferred image model: **Nano Banana 2.1 at 4K** – it gave the user a realistic result where GPT Image 2.6 (1k, "low" quality default) looked fake.
- Never use low-quality / 1k defaults for frames meant for posting; always request the highest resolution/quality the model allows.
- Before generating, check the model catalog (Higgsfield `models_explore`) for Nano Banana / the latest photoreal model and use it.
- Prompt for realism: shot on iPhone, natural imperfect lighting, real skin texture with pores and fine lines, candid unposed moment, slight motion/handheld feel, ordinary real-world setting – avoid "perfect", glossy, studio, model-like looks.
- If I cannot view a generated result myself, say so and ask the user to check it before building on it.
- Only generate through Higgsfield when the user explicitly asks; otherwise write prompts for the user to run.
