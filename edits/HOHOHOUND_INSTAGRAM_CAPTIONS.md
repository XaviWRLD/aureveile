# HoHoHound – all 16 Reels + Instagram captions (German)

All files are in **HoHoHound_All_Reels_Instagram.zip**. 1080×1920, Instagram-ready.

**Instagram rules used here:**
- Links in captions aren't clickable on Instagram, so every caption says **„Link in der Bio“** and asks people to comment **SANTA**. Reply to each SANTA comment with a DM containing the link (or set up ManyChat to do it automatically). Every reply counts as engagement.
- Max **5 hashtags** (Instagram now limits hashtags; fewer, relevant ones work best).
- The songs are added in the video. If Instagram mutes one for a business account, re-add the same song from Instagram's music library when posting.

**Posting:** 1 Reel per day (max 2), always a different format. Order below = recommended order. Skip the duplicates marked ⚠️ unless a Schatz version takes off.
