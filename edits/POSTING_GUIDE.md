## Which file to post
- `*_TRENDSOUND.mp4`: real foley only (button clicks, strap). In TikTok/IG, tap **Add sound**, pick the song above, and drag the start so a strong downbeat hits frame 1. For v2, set the start so the chorus hit or drop lands at 7.2s. Set original audio to about 20% so the clicks stay audible (ASMR helps retention). Native sounds get your post onto the sound's page, which drives most of the reach.
- `*_READY.mp4`: same edit with an original, copyright-free beat at the same BPM baked in. Post as-is from a **business/shop account** (business accounts can't use the major-label songs above) or for ads.

## Posting tips
- Captions sit in the 70–79% band, clear of the product and of the TikTok/IG UI.
- Lengths are 11.2s, 11.7s and 13.5s, short enough to loop and push completion rate above 100%.
- Post one per day rather than all at once, since each tests a different hook.
- Holiday sounds peak from late November to Christmas, so post soon.
